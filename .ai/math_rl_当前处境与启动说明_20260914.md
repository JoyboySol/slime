# Math RL 当前处境与启动说明

更新时间：2026-09-14

## 1. 当前结论

目前 HF 权重加载、SGLang rollout、MCore checkpoint 加载、sqrt-gate 配置和 rollout 文本质量都已经验证正常。rollout 输出不是乱码。

当前真正未解决的问题是 MoE rollout 与 MCore actor 的 logprob 对齐：

```text
train/train_rollout_logprob_abs_diff = 0.574544
```

未开启 route replay 的全量训练中，该值明显超过配置的 CI 阈值 `0.1`。route replay 的代码链路已经可以运行，但最新 B 实验的指标反而为 `1.065276`，因此 route replay 目前还不能直接作为正式训练配置。



这证明当前 MoE rollout 与 actor 的 logprob 存在明显不一致，但不能单凭该实验证明唯一根因就是 route replay。

### B1：打开开关，但没有注入 Megatron route replay patch

日志：

```text
/mnt/yulan/lvzhihao/PostTrain/outputs/logs/yulan_moe_routing_replay_smoke_B_20260914.log
```

配置中两个开关均为 `True`，SGLang 也设置了 `enable_return_routed_experts=True`。但当时 YuLan-Pretrain 的 Megatron 源码没有实际注册 `RoutingReplay`，训练在填充 replay 数据时失败：

```text
IndexError: RoutingReplay.all_routing_replays[routing_replay_offset]
```

结论：仅打开 slime 参数不够，Megatron router 必须注册 replay hook，同时 `moe_utils.py` 必须走 replay-aware 的 `compute_topk`。

### B2：应用 route replay Megatron patch 后重跑

使用 patch：


该 patch 注入两处逻辑：

1. 在 `TopKRouter` 初始化时调用 `register_routing_replay(self)`；
2. 在 `topk_routing_with_score_function` 中包装 `compute_topk`，支持 `record`、`replay_forward` 和 `replay_backward`。

SGLang 侧确认：


训练侧确认：


## 5. 当前主要风险

1. `train_rollout_logprob_abs_diff` 仍然不可靠，route replay B2 没有改善它。
2. B2 使用短 response，且有 `truncated_ratio=0.5`，因此不能把绝对数值直接外推到 31744 response 的正式训练；但 `1.065` 仍足以说明对齐存在问题。
3. 当前 route replay 需要进一步验证 routed experts 的 token 顺序、prompt/response 拼接边界、CP 分片顺序、layer 顺序以及 EP rank 映射。
4. 正式配置使用 `REBUILD_TRAIN_ACTORS=1` 时必须传 `SAVE_HF`。
5. TE FusedAdam 的 GPU OOM 与 route replay 是两个独立问题；不能通过 route replay 解决 optimizer 显存峰值。

## 6. 下一步建议

正式训练前建议先做一个更严格的 route 对齐诊断：

1. 保存 B2 的完整 rollout 数据，尤其是 `rollout_routed_experts`；
2. 在 actor 侧逐层比较 SGLang routed experts 与 MCore replay 输入的 shape、token 数和 expert id；
3. 分别测试 prompt-only、response-only 和完整序列的 logprob diff；
4. 验证 CP=8 下 routed experts 的分片是否与 `prepare_routed_experts_for_routing_replay` 完全一致；
5. 修复后再以 `global_batch=8` 做 A/B，最后才扩大到 `global_batch=256`。

在 route replay 指标稳定低于 `0.1` 之前，不建议把 `--use-rollout-routing-replay` 直接加入全量训练。

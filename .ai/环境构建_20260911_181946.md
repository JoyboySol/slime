## 2. 环境构建过程

### 2.1 复制 YuLan 基础环境

原有 `.venv` 未直接删除，而是先保留为备份：

```bash
cd /mnt/yulan/lvzhihao/PostTrain/slime

mv .venv .venv.before-env-build
rsync -a --delete \
  /mnt/yulan/lvzhihao/PostTrain/YuLan-Pretrain/.venv/ \
  .venv/
```

修复虚拟环境中的旧路径：

```bash
OLD=/mnt/yulan/lvzhihao/PostTrain/YuLan-Pretrain/.venv
NEW=/mnt/yulan/lvzhihao/PostTrain/slime/.venv

sed -i "s|$OLD|$NEW|g" "$NEW/pyvenv.cfg"

for file in "$NEW/bin/activate" \
            "$NEW/bin/activate.csh" \
            "$NEW/bin/activate.fish"; do
  [ -f "$file" ] && sed -i "s|$OLD|$NEW|g" "$file"
done

for file in "$NEW/bin/"*; do
  if [ -f "$file" ] && head -n 1 "$file" | grep -q "$OLD"; then
    sed -i "1 s|$OLD|$NEW|" "$file"
  fi
done
```
